# ⚡ VoltaLab

**VoltaLab** es una plataforma interactiva y educativa diseñada para visualizar, simular y comprender fenómenos físicos de ondas, interferencias y conceptos electrodinámicos de manera intuitiva.

🚀 **Demo en vivo:** [https://voltalab1.vercel.app](https://voltalab1.vercel.app) *(reemplaza con tu enlace de Vercel si es diferente)*

---

## 📸 Características principales

* **Simulaciones en tiempo real:** Visualización interactiva de fenómenos de interferencia constructiva y destructiva.
* **Componentes didácticos:** Experimentos interactivos con fuentes de onda ($S_1$, $S_2$) y medición en puntos específicos (boya $P$).
* **Interfaz moderna y fluida:** Construido para una experiencia de usuario rápida, clara y responsiva.

---

## 🛠️ Tecnologías utilizadas

* **Frontend:** React / Vite
* **Estilos:** CSS Modules / Tailwind CSS
* **Despliegue:** [Vercel](https://vercel.com/)
* **Control de versiones:** Git & GitHub
